# 튜토리얼 안내 문구
#
# 형식: RowName=문구
#   - RowName은 DT_TutorialSteps의 Row Name과 정확히 같아야 합니다.
#   - 여기 없는 Row는 DataTable에 입력된 instruction 값을 그대로 씁니다.
#   - 줄바꿈이 필요하면 \n 두 글자를 넣으세요.
#   - 빈 줄과 # · // 로 시작하는 줄은 무시됩니다.
#   - "RowName.pointer=위젯이름" 은 화살표로 가리킬 UI 위젯입니다.
#     WBP_HUD 디자이너에 있는 이름을 그대로 적습니다 (StaminaBar / HealthBar / ExpBar 등).
#     @EquippableSlot 을 적으면 인벤토리에서 지금 캐릭터가 장착할 수 있는 장비가 든 칸 하나를 가리킵니다.
#     @StatBonus 를 적으면 스탯창에서 "(+N)" 증가분이 붙어 있는 스탯 텍스트를 전부 네모로 강조합니다.
#   - "RowName.hint=문구" 는 화살표 옆에 뜨는 보조 설명입니다.
#     (pointer 또는 DataTable의 pointerTargetClass가 설정된 단계에서만 표시됩니다.)
#   - pointer에 쉼표로 여러 이름을 적으면 각각 노란 네모로 강조합니다 (예: WBP_UseItem1,WBP_UseItem2).
#     이때 hint는 | 로 나눠 같은 순서로 적습니다 (예: 1번을 누르면 사용됩니다|2번을 누르면 사용됩니다).
#   - "RowName.reveal=items" 는 그 단계에 진입할 때 레벨의 아이템을 등장시킵니다.
#     튜토리얼 시작 시점에는 숨겨져 있어 보이지도, 주울 수도 없습니다.
#     items 대신 Actor Tag 이름을 적으면 그 태그를 가진 액터가 등장합니다.
#   - "RowName.pauseHit=문구" 를 적으면 그 단계에서 스폰한 몬스터의 공격이 맞기 직전에 멈추고 이 문구가 뜹니다.
#     "RowName.resumeTag=태그" 를 가진 순간(예: State.Shield — 실드를 켠 순간) 공격이 이어집니다. 둘 다 있어야 동작합니다.
#   - "RowName.requireMove=true" 를 적으면 키를 누른 것만으로는 인정하지 않고,
#     캐릭터가 실제로 움직이는 동안만 게이지가 찹니다 (공격 중에 WASD만 눌러도 안 참).
#     true 대신 숫자를 적으면 그 속도(cm/s) 이상일 때만 인정합니다. false면 검사하지 않습니다.
#   - "RowName.requireAttack=true" 를 적으면 키를 누른 횟수가 아니라
#     실제로 공격 몽타주가 재생된 횟수로 셉니다 (쿨다운 중 좌클릭 연타는 안 세어짐).
#     true 대신 몽타주 이름 조각을 적으면 그 이름이 든 몽타주만 인정합니다
#     (예: MeleeAttack → AM_MeleeAttack_A/B/C · Fire → Primary_Fire_Med_Montage).
#     회피 등 다른 몽타주가 섞이는 단계에서는 반드시 이름 조각을 적으세요.
#   - "RowName.count=숫자" 는 그 단계에 필요한 횟수를 DataTable 대신 여기서 정합니다.
#   - "RowName.event=태그" 를 적으면 키 입력 대신 그 게임 이벤트가 일어나야 단계가 완료됩니다.
#     (예: Event.Tutorial.QuickSlotUsed — 퀵슬롯에 등록한 아이템을 실제로 사용해 재고가 줄어든 순간)
#     태그는 DefaultGameplayTags.ini에 있어야 하며, ini를 고친 뒤에는 에디터를 재시작해야 합니다.
#   - "_Completed=문구" 는 모든 단계를 마쳤을 때 마지막으로 뜨는 문구입니다.
#
# 저장할 때 인코딩을 반드시 UTF-8로 하세요. ANSI로 저장하면 한글이 깨집니다.
#   (메모장: 다른 이름으로 저장 → 인코딩 드롭다운 → UTF-8)
#
# 이 파일은 레벨 시작 시 한 번만 읽습니다. 문구를 고친 뒤에는 PIE를 다시 시작하세요.
