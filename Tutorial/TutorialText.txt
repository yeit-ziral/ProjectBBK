# 튜토리얼 안내 문구
#
# 형식: RowName=문구
#   - RowName은 DT_TutorialSteps의 Row Name과 정확히 같아야 합니다.
#   - 여기 없는 Row는 DataTable에 입력된 instruction 값을 그대로 씁니다.
#   - 줄바꿈이 필요하면 \n 두 글자를 넣으세요.
#   - 빈 줄과 # · // 로 시작하는 줄은 무시됩니다.
#   - "RowName.pointer=위젯이름" 은 화살표로 가리킬 UI 위젯입니다.
#     WBP_HUD 디자이너에 있는 이름을 그대로 적습니다 (StaminaBar / HealthBar / ExpBar 등).
#   - "RowName.hint=문구" 는 화살표 옆에 뜨는 보조 설명입니다.
#     (pointer 또는 DataTable의 pointerTargetClass가 설정된 단계에서만 표시됩니다.)
#   - "RowName.reveal=items" 는 그 단계에 진입할 때 레벨의 아이템을 등장시킵니다.
#     튜토리얼 시작 시점에는 숨겨져 있어 보이지도, 주울 수도 없습니다.
#     items 대신 Actor Tag 이름을 적으면 그 태그를 가진 액터가 등장합니다.
#   - "_Completed=문구" 는 모든 단계를 마쳤을 때 마지막으로 뜨는 문구입니다.
#
# 저장할 때 인코딩을 반드시 UTF-8로 하세요. ANSI로 저장하면 한글이 깨집니다.
#   (메모장: 다른 이름으로 저장 → 인코딩 드롭다운 → UTF-8)
#
# 이 파일은 레벨 시작 시 한 번만 읽습니다. 문구를 고친 뒤에는 PIE를 다시 시작하세요.

01_MoveForward=W를 눌러 앞으로 이동하세요
02_MoveBack=S를 눌러 뒤로 이동하세요
03_MoveSide=A 또는 D로 좌우로 이동하세요
04_Look=마우스를 움직여 시점을 돌려보세요
05_Sprint=Shift를 눌러 달려보세요
05_Sprint.pointer=StaminaBar
05_Sprint.hint=달릴 시 스태미나를 소모합니다
06_Dodge=Space를 눌러 돌진하세요
06_Dodge.pointer=StaminaBar
06_Dodge.hint=대쉬를 할 시 스태미나를 소모합니다
07_Attack=좌클릭으로 공격하세요
07_Attack.pointer=StaminaBar
07_Attack.hint=공격을 할 시 스태미나를 소모합니다
08_Shield=C를 눌러 적의 공격을 2번 막으세요
09_UniqueSkill=E를 눌러 고유 스킬을 사용하세요
10_Ultimate=Q를 눌러 궁극기로 적을 공격하세요
10_Ultimate.hint=이것이 마나입니다.\n마나가 가득 차면 궁극기를 사용 할 수 있습니다
11_SwitchChar=Tab을 눌러 캐릭터를 교체하세요
12_SkillWheel=Z를 눌러 스킬 휠을 여세요
13_CommonSkill=F를 눌러 스킬을 사용하세요
14_Interact=G를 눌러 아이템을 획득하세요
14_Interact.reveal=items
15_Inventory=I를 눌러 인벤토리를 여세요
16_Equipment=O를 눌러 장비창을 여세요
17_QuickSlot=1을 눌러 퀵슬롯 아이템을 사용하세요

# 전체 완료 문구
